# ClassMate — Домашние задания

Общий сайт для школьного класса: ученики добавляют домашние задания, указывают предмет и срок, а весь класс видит одну и ту же общую базу заданий.

## Что умеет

**Главная.** Приветствие, ближайший дедлайн, счётчики «Сегодня / Завтра / На неделю / Просрочено», полоса на ближайшие 7 дней с количеством заданий. Блоки «На сегодня», «Скоро сдавать» и «Просроченные».

**Задания.** Добавление через кнопку «+ Добавить задание». Поля: предмет (готовые варианты или свой), что задали, дата сдачи (быстрые кнопки «Завтра», «Через неделю»), страница и упражнение, комментарий, фото. Автор подставляется автоматически. Задание сразу появляется у всех участников класса.

**Список.** Фильтры: все, на сегодня, на завтра, на неделю, по предмету, выполненные, невыполненные. Поиск по тексту. У каждого задания есть кнопка «Отметить как выполненное». Отметка личная: у одноклассников она не меняется.

**Календарь.** Виды «день», «неделя» и «месяц». У каждого предмета свой цвет, на каждом дне видно число заданий. Нажатие на день показывает задания и даёт добавить новое на эту дату.

**Уведомления.**
- Напоминание за день до сдачи и в день сдачи, в выбранное время, по часовому поясу ученика.
- Уведомления о новых заданиях одноклассников.
- Отдельная страница со всеми уведомлениями.
- Push-уведомления браузера, которые приходят и при закрытом сайте.

**Класс.** Регистрация и вход. Класс с уникальным кодом приглашения. Роли:
- Администратор: редактирует и удаляет любые задания, назначает других администраторов, исключает участников, меняет код.
- Ученик: редактирует и удаляет только свои задания.

**Дополнительно.** Фото к заданиям (до 6 шт., до 5 МБ), статистика выполнения (по предметам и самые активные авторы), копирование задания, светлая и тёмная темы. Мобильная версия с нижним меню, на компьютере боковое меню.

## Запуск

Нужен Python 3.10+.

```bash
cd classmate
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Откройте http://localhost:8000. Первый ученик регистрируется и создаёт класс, на экране «Мой класс» появится код приглашения. Остальные регистрируются и вводят этот код.

## Как выложить для всего класса

Сайт должен работать на сервере, доступном из интернета (VPS, Render, Railway, PythonAnywhere и т. п.), и **по HTTPS**: без HTTPS браузеры не разрешают push-уведомления.

```bash
pip install -r requirements.txt
export CLASSMATE_SECRET_KEY="длинная-случайная-строка"
export CLASSMATE_SECURE_COOKIES=1
export CLASSMATE_VAPID_SUBJECT="mailto:ваш-email@example.com"
gunicorn --workers 1 --threads 8 --bind 0.0.0.0:8000 app:app
```

Перед gunicorn поставьте веб-сервер с HTTPS (nginx/Caddy) или используйте HTTPS хостинга. Каталог `data/` должен сохраняться между перезапусками.

| Переменная | Назначение |
|---|---|
| `CLASSMATE_DATA_DIR` | Где хранить базу, фото и ключи (по умолчанию `classmate/data`) |
| `CLASSMATE_SECRET_KEY` | Ключ подписи сессий. Если не задан, создаётся в `data/secret_key` |
| `CLASSMATE_SECURE_COOKIES` | `1` — cookie только по HTTPS (включите в продакшене) |
| `CLASSMATE_VAPID_SUBJECT` | Контакт для push-сервисов, `mailto:…` |
| `CLASSMATE_DISABLE_SCHEDULER` | `1` — отключить фоновую проверку напоминаний |
| `PORT` | Порт для `python app.py` (по умолчанию 8000) |

**Резервная копия:** достаточно скопировать каталог `data/` (там `classmate.db`, фото в `uploads/` и ключи).

## Как это устроено

- **Сервер:** Flask + SQLite (`app.py`, `db.py`). Все данные в базе, ничего не выдумано на клиенте.
- **Синхронизация:** каждые 15 секунд страница делает лёгкий запрос `/api/sync`. Если у класса изменилась «версия» (кто-то добавил, изменил или удалил задание), список перезагружается. Сразу проверка выполняется при возврате на вкладку.
- **Напоминания** (`reminders.py`): фоновый поток раз в минуту создаёт напоминания, когда у ученика наступило выбранное время. Уникальный ключ в базе не даёт отправить одно напоминание дважды. Push отправляется через Web Push (VAPID): ключи создаются автоматически в `data/vapid_private.pem`.
- **Интерфейс:** чистый HTML/CSS/JavaScript без сборки (`static/`). Service worker (`static/sw.js`) показывает push, когда сайт закрыт.

## Безопасность

- Пароли хранятся только в виде хэша (Werkzeug, scrypt).
- Сессия в подписанной cookie с флагами `HttpOnly` и `SameSite=Lax`, в продакшене ещё и `Secure`.
- Защита от перебора пароля и кода приглашения.
- Каждый запрос проверяет, что задание или фото принадлежит классу пользователя. Чужие классы недоступны.
- Права проверяются на сервере: правка и удаление только для автора или администратора.
- Загружаемые файлы проверяются по содержимому: принимаются только JPG, PNG, GIF, WebP.
- Заголовки безопасности (CSP, `X-Frame-Options`, `nosniff`). Весь пользовательский текст экранируется.
- SQL-запросы только с параметрами.

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest tests
```

Тесты проверяют регистрацию, общий доступ к заданиям, права автора и администратора, изоляцию классов, личные отметки «выполнено», фото, уведомления, напоминания с учётом времени и часового пояса, управление классом и push-подписки.
