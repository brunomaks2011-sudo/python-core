# BrickGen

Сайт, который превращает короткое описание («красная спортивная машина», «робот») в модель из настоящих
деталей LDraw. Он подбирает заготовку, собирает и проверяет её в [LDraw Nova](https://github.com/anteloc/ldraw-nova),
показывает результат в 3D и даёт скачать MPD, GLB и список деталей.

Это первая фаза плана «Архитектура сайта генерации LEGO-моделей»: быстрый черновик из проверенных заготовок.
Генерация новой геометрии по описанию — следующая фаза.

## Как это работает

```
запрос ─► планировщик ─► план LDraw Nova ─► ldraw-agent review ─► ldraw-agent glb ─► страница результата
          Claude или      рецепт машины,     сборка MPD, проверки,  GLB для 3D-просмотра
          правила         пример, генератор  рендеры LeoCAD
```

1. **Планировщик** (`brickgen/planner.py`) выбирает заготовку, палитру и цвета частей. Если задан
   `ANTHROPIC_API_KEY`, выбор делает Claude: ответ ограничен JSON-схемой каталога, так что модель может назвать
   только существующие заготовки, роли и цвета. Без ключа или при ошибке API работают правила по ключевым словам.
   Запрос, который не похож ни на одну заготовку, отклоняется с подсказкой.
2. **Каталог** (`brickgen/catalog.py`) — 31 заготовка:
   - 7 машин из рецептов `ldraw-agent vehicle plan`: спорткар, фургон, пикап, самосвал, мотоцикл, катер, самолёт;
   - космический истребитель и 21 здание из проверенных примеров LDraw Nova;
   - экскаватор и робот — собственные параметрические генераторы (`brickgen/generators/`), потому что в LDraw Nova
     таких рецептов нет. Цвета частей берутся из запроса.
3. **Конвейер** (`brickgen/pipeline.py`) перекрашивает план и запускает `ldraw-agent review`: сборка MPD,
   проверка геометрии и соединений, рендеры LeoCAD и сверка списков деталей. Затем `ldraw-agent glb` готовит GLB.
4. **Очередь** (`brickgen/jobs.py`) — пул потоков и папка на каждое задание с `job.json`. Есть лимит длины
   очереди и лимит сборок в час с одного адреса. Задания, прерванные перезапуском, помечаются как неудачные.
5. **Сайт** (`brickgen/web.py`, `brickgen/static/`) — FastAPI и страница без сборщика. На ней форма, этапы сборки,
   3D-просмотр на three.js, снимок LeoCAD, итоги проверок, список деталей и скачивание файлов. Список
   «Мои модели» хранится в браузере посетителя; общей галереи нет.

LDraw Nova вызывается только через командную строку `ldraw-agent`; её код и папка не меняются.

## Установка

Ubuntu 24.04, сервер или облачная сессия Claude Code:

```sh
scripts/setup.sh
```

Скрипт ставит LeoCAD 25.09, Xvfb и Mesa, библиотеку деталей LDraw (зеркало
[kulits/ldraw-parts](https://github.com/kulits/ldraw-parts)), LDraw Nova, mpd2glb 0.9.1 (через Bun),
Python-зависимости (uv или pip) и three.js (npm). Папки меняются переменными `LDRAW_NOVA_DIR`, `LDRAW_DIR`
и `BRICKGEN_TOOLS`.

## Запуск

```sh
export LDRAW_NOVA_DIR=~/ldraw-nova LDRAW_DIR=~/ldraw BRICKGEN_EXTRA_PATH=~/.local/share/brickgen/bin
export ANTHROPIC_API_KEY=...   # необязательно: без ключа заготовку выбирают правила
.venv/bin/python -m brickgen --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000. Шесть тем со стартовой страницы собираются за 11–33 секунды на облачной машине
без видеокарты (LeoCAD рисует программно); ответ Claude добавляет несколько секунд.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `LDRAW_NOVA_DIR` | `~/ldraw-nova` | папка LDraw Nova с `ldraw-agent` и `.venv` |
| `LDRAW_DIR` | `~/ldraw` | библиотека деталей LDraw |
| `BRICKGEN_DATA_DIR` | `./data` | папки заданий |
| `ANTHROPIC_API_KEY` | — | включает выбор заготовки через Claude |
| `BRICKGEN_MODEL` | `claude-opus-5-5` | модель Claude для планировщика |
| `BRICKGEN_PLANNER` | `auto` | `rules` — не обращаться к Claude даже при наличии ключа |
| `BRICKGEN_WORKERS` | `2` | сколько моделей собирается одновременно |
| `BRICKGEN_MAX_QUEUE` | `20` | сколько заданий может ждать в очереди |
| `BRICKGEN_JOBS_PER_HOUR` | `30` | лимит сборок в час с одного адреса |
| `BRICKGEN_EXTRA_PATH` | — | добавляется в `PATH` для `leocad`, `mpd2glb.sh`, `xvfb-run` |
| `BRICKGEN_XVFB` | `auto` | запускать LeoCAD через `xvfb-run`; `auto` — если нет `DISPLAY` |
| `BRICKGEN_REVIEW_TIMEOUT`, `BRICKGEN_GLB_TIMEOUT` | `300` | ограничения времени в секундах |
| `BRICKGEN_THREE_URL` | — | откуда браузер грузит three.js; по умолчанию `node_modules`, без него CDN |

За обратным прокси (nginx, Caddy) на той же машине сервер берёт адрес посетителя из `X-Forwarded-For`, и лимиты
считаются по нему. Если прокси на другом адресе, укажите его в `FORWARDED_ALLOW_IPS`.

## API

| Метод | Путь | Ответ |
|---|---|---|
| `POST` | `/api/jobs` `{"prompt": "..."}` | `202 {"id": ...}`; `429` — лимит, `503` — очередь полна |
| `GET` | `/api/jobs/{id}` | состояние, этапы, выбранная заготовка, итоги проверок, детали, файлы |
| `GET` | `/files/{id}/{name}[?download=1]` | `model.mpd`, `model.glb`, `parts.csv`, `model.plan.json`, `preview.png`, `front.png`, `top.png`, `review.json`, `validation.json` |
| `GET` | `/api/themes` | шесть быстрых тем и каталог заготовок |
| `GET` | `/api/health` | режим планировщика и наличие инструментов |

## Тесты

```sh
.venv/bin/python -m pytest            # быстрые тесты; проверки по библиотеке LDraw пропускаются, если её нет
.venv/bin/python -m pytest -m slow    # шесть тем целиком через LDraw Nova, LeoCAD и mpd2glb
```

## Как добавить заготовку

- **Пример или рецепт LDraw Nova.** Добавьте `Template` в `brickgen/catalog.py`: ключевые слова, роли для
  перекраски (код цвета в исходном плане и, при необходимости, секции) и атрибуцию.
- **Свой генератор.** Напишите функцию `build(colours) -> plan` в `brickgen/generators/`, зарегистрируйте её
  через `@register("имя")` и добавьте `Template` с `kind="generator"`. Координаты в LDU: X — ширина,
  −Y — вверх, −Z — перёд; высота кирпича 24, пластины 8, шаг шипа 20. Проверяйте план командой
  `ldraw-agent review` и смотрите рендеры; добавьте тему в `tests/test_integration.py`.

## Ограничения первой фазы

- Новая геометрия не создаётся: запрос сводится к ближайшей заготовке и цветам. Отличия от запроса
  планировщик перечисляет в пояснениях.
- В генераторах экскаватора и робота часть соединений (подвешенные руки, Technic-штифты) проверка
  LDraw Nova не распознаёт и показывает предупреждение о нескольких группах деталей. Ошибок геометрии нет.
- Задания хранятся на диске без очистки; для публичного сайта нужна периодическая чистка `data/jobs`.
