        Как это работает

        1. Понимаем запрос. Claude выбирает ближайшую проверенную заготовку и цвета. Без ключа API работает подбор по ключевым словам.
        2. Собираем. LDraw Nova строит модель из настоящих деталей библиотеки LDraw.
        3. Проверяем. Файл, геометрия, пересечения кубиков и список деталей; LeoCAD открывает и рисует модель.
        4. Отдаём. 3D-просмотр в браузере, файл LDraw (.mpd) для LeoCAD или Studio и GLB для 3D-программ.
