Design ID — номер форми деталі

Це номер самої форми, незалежно від кольору: наприклад, 3001 — цеглинка 2 × 4. На багатьох деталях він дрібно вибитий на внутрішній стороні. Введіть його в пошук деталей, щоб побачити всі доступні кольори.

Element ID — деталь у конкретному кольорі

Element ID позначає певну деталь у певному кольорі. Його можна знайти на останніх сторінках інструкції LEGO, де перелічено всі деталі набору: під зображенням кожної деталі є номер елемента. Пошук на сайті розуміє і Element ID.

Номер кольору

Ми використовуємо нумерацію кольорів BrickLink (наприклад, 5 — Red, 11 — Black, 86 — Light Bluish Gray). Повний список — у таблиці кольорів.

Номер набору та мініфігурки

Номер набору вказано на коробці та інструкції (наприклад, 75355). Мініфігурки шукайте за номером каталогу або назвою персонажа.

Великий список деталей?

Скористайтеся замовленням списком: вставте рядки «номер колір кількість» — і всі доступні позиції потраплять у кошик.
