Колонки для деталей

design_id
Номер деталі (3001). Обов'язково, якщо немає element_id
color_id
Номер кольору BrickLink (5 = Red) або RB4 для Rebrickable
color
…або назва кольору (Red / Червоний)
element_id
Element ID — визначає деталь і колір
condition
new / used (новий / б/у)
quantity
Залишок, шт.
price
Ціна за 1 шт., ₴ (крапка або кома)
location
Місце на складі (A-01-03)
name_uk
Українська назва деталі (необов'язково)

Номери перевіряються за офіційним каталогом. Рядки з неіснуючими номерами потрапляють у звіт як помилки — нічого не вигадується.
