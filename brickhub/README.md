# BRICK HUB — интернет-магазин LEGO для Украины

Полноценный магазин оригинальной продукции LEGO: наборы, **отдельные детали по номеру и цвету** (как на BrickLink) и минифигурки. Интерфейс на украинском, цены в гривнах (₴).

Стек: **Python 3.13 · Django 5.2 LTS · SQLite или PostgreSQL**. Страницы рендерятся на сервере (быстро и хорошо для SEO), JavaScript используется только для удобства: подсказки поиска, мини-корзина, автодополнение Новой почты. Без него всё работает.

## Что умеет

**Витрина**
- Главная: баннер «Світ LEGO починається тут!», кнопки «Перейти до каталогу» и «Знайти деталі», популярные товары, новинки, хиты продаж, последние поступления, популярные минифигурки, серии и категории деталей, преимущества, доставка по Украине.
- Каталог: наборы по сериям (City, Technic, Star Wars, Icons, Creator, Speed Champions, Harry Potter, NINJAGO, Marvel, Minecraft, Friends, Architecture, Ideas, Super Mario, другие); детали по категориям (цеглинки, пластини, плитки, колеса, вікна/двері, крила, шестерні, Technic, прозорі, рослини, аксесуари, інші); минифигурки по сериям; брелоки; книги с фигурками; аксессуары; подборки «Новинки», «Розпродаж», «Набори б/у», «Рідкісні».
- Поиск по названию (укр./англ.), номеру набора, Design ID, Element ID, номеру минифигурки (каталожному или BrickLink sw0001), цвету («3001 червоний», «3023 black») и серии. Подсказки появляются прямо при вводе.
- Фильтры: цена, тип, категория, серия, цвет (палитра), состояние, наличие, год, количество деталей. Сортировка по популярности, новизне, цене, названию и рейтингу.
- Карточка товара: галерея со стрелками, номера с кнопкой копирования, выбор цвета детали (список и квадратики цветов, у каждого цвета своё фото, цена и остаток), переключатель «Новий / Б/у», цена, наличие, количество, корзина, избранное, сравнение, характеристики (детали, минифигурки, год, возраст, размеры), комплектация минифигурки, отзывы и рейтинг, похожие и недавно просмотренные товары, «Повідомити про надходження».
- Страница детали `/detali/3001/` — таблица всех цветов: номер цвета BrickLink, Element ID, состояние, остаток, цена за штуку. Можно сразу положить в корзину несколько цветов.
- **Заказ деталей списком**: вставляете строки вида `3001 5 10` или `3023 Black 24`, и всё, что есть в наличии, попадает в корзину.
- Справочник цветов LEGO с номерами BrickLink и Rebrickable.

**Корзина и заказ**
- Корзина в базе данных: у гостя по сессии, у покупателя в аккаунте; при входе они объединяются. Количество не может превысить остаток.
- Промокоды: процент или фиксированная сумма, минимальная сумма заказа, только на наборы/детали/минифигурки, лимит использований, срок действия, один раз на покупателя.
- Оформление: имя, фамилия, телефон (проверяется украинский формат), e-mail, город, отделение или почтомат Новой почты, курьер, Укрпошта с индексом, способ оплаты, комментарий, создание аккаунта.
- При заказе товар списывается со склада внутри транзакции, поэтому одну и ту же последнюю штуку не продадут двоим. Каждое движение по складу записывается в журнал.
- Письма покупателю (заказ принят, смена статуса) и менеджеру (новый заказ).

**Личный кабинет**: регистрация, вход по e-mail, восстановление пароля, личные данные и адрес доставки, история заказов, статус-таймлайн и ТТН со ссылкой отслеживания, «Повторить заказ», отмена, избранное, подписки на поступление. Отследить заказ можно и без аккаунта — по номеру и телефону.

**Админ-панель `/panel/`** (только для сотрудников)
- Статистика: выручка за день, 7 и 30 дней, средний чек, график по дням, заказы по статусам, топ товаров, заканчивающиеся товары, стоимость склада.
- Товары: типы «Набір», «Деталь», «Мініфігурка», «Брелок», «Книга з фігуркою», «Аксесуар»; у брелока и книги можно указать номер LEGO и минифигурку в комплекте (необязательно). Цвет, серия и категория выбираются полем с поиском: начните вводить название по-украински, по-английски или номер цвета. Поиск, фильтры, правка цены и остатка прямо в таблице, массовые действия, добавление и редактирование с **автозаполнением из каталога по номеру LEGO**, загрузка нескольких фото (уменьшаются, превью WebP), место на складе, журнал движения.
- Заказы: смена статусов с письмом покупателю. Отмена и возврат автоматически возвращают товар на склад. Ввод ТТН переводит заказ в «Відправлене». Есть пакувальний лист, отсортированный по месту на складе.
- Пользователи (блокировка, права сотрудника), промокоды, отзывы (модерация), подписки на поступление.
- Справочники: категории, серии, цвета, каталог деталей, Element ID, каталог наборов и минифигурок.
- **Массовый импорт CSV / Excel (.xlsx)** на тысячи строк: детали, наборы, минифигурки, обновление остатков и цен по артикулу. Сначала режим «Перевірити без збереження» с отчётом по строкам, потом запись. Номера сверяются с официальным каталогом. Есть шаблоны .xlsx и экспорт всех товаров в CSV.
- Системная админка Django `/django-admin/` для суперпользователя.

## Быстрый старт

```bash
cd brickhub
```

```bash
python3 -m venv .venv
```

```bash
source .venv/bin/activate
```

Windows: `.venv\Scripts\activate`

```bash
pip install -r requirements.txt
```

```bash
cp .env.example .env
```

```bash
python manage.py setup_store
```

```bash
python manage.py createsuperuser
```

```bash
python manage.py runserver
```

`setup_store` создаёт таблицы, загружает справочный каталог LEGO (≈26 000 наборов, 62 000 деталей, 17 000 минифигурок, 275 цветов) и демо-ассортимент магазина. Без демо-товаров: `python manage.py setup_store --no-demo`.

Откройте http://127.0.0.1:8000/ (магазин) и http://127.0.0.1:8000/panel/ (админка, вход под созданным суперпользователем).

Тесты:

```bash
python manage.py test tests
```

## Откуда данные и что в них настоящее

| Данные | Источник |
| --- | --- |
| Номера наборов, названия, годы, количество деталей и минифигурок | Каталог [Rebrickable](https://rebrickable.com/downloads/) |
| Номера деталей (Design ID), официальные названия, типы | Rebrickable |
| Цвета: названия, HEX, номера Rebrickable | Rebrickable |
| Номера цветов BrickLink (106 цветов) | Сопоставлены по названию с данными BrickLink |
| Комплектация минифигурок, в каких наборах встречаются | Rebrickable |
| Украинские названия деталей, цветов и категорий | Переведены для магазина (официальное английское название показывается рядом) |
| **Цены, остатки, флаги «Новинка/Хит», промокоды WELCOME10 / DETALI15 / MINIFIG100** | **Демо-значения.** Замените их в админке или импортом |

Номера деталей **не выдумываются**. Форма товара и импорт проверяют каждый номер по каталогу, а неизвестные номера попадают в отчёт как ошибка. Создать новую запись каталога можно только явно: галочка «створити запис вручну» плюс официальное название, для позиций, которых ещё нет в справочнике.

**Element ID.** В каталоге из коробки их нет. Скачайте `elements.csv` с rebrickable.com/downloads и выполните `python manage.py import_catalog --csv-dir ПАПКА`. Так же обновляется весь каталог новыми наборами. Element ID можно вводить и вручную: в карточке товара, в справочнике или колонкой `element_id` при импорте. После загрузки выполните `python manage.py rebuild_search_index`.

**Номера минифигурок BrickLink (sw0001 и т. п.)** в открытых данных отсутствуют. В демо используются каталожные номера Rebrickable (`fig-000123`), а поле «Номер BrickLink» заполняется в админке. Поиск понимает оба варианта.

**Фото.** На сайте показываются только фото, которые добавили вы: загруженные файлы или ссылки, вставленные в админке. Ничего не подтягивается автоматически: у товара без фото стоит заглушка «Фото незабаром». В списке товаров админки есть фильтр «Без фото». Фото, подставленные раньше из каталога Rebrickable, убирает команда `python manage.py clear_auto_images`.

## Импорт CSV / Excel

Админка → «Імпорт CSV / Excel». Шаблоны .xlsx скачиваются там же. Поддерживаются UTF-8 и Windows-1251, разделитель `;` или `,`, десятичная запятая. Названия колонок можно писать по-английски или по-украински («Номер деталі», «Колір», «Кількість», «Ціна»…).

Детали (до 50 000 строк, новые записываются пакетами):

```
design_id;color_id;condition;quantity;price;location
3001;5;new;250;6,00;A-01-03
3023;11;new;1200;2,00;A-02-11
3069b;;used;40;1,50;B-07-01        ← без color_id нужна колонка color (название)
```

- `color_id` — номер цвета BrickLink (5 = Red, 11 = Black, 86 = Light Bluish Gray), `RB4` — номер Rebrickable, либо колонка `color` с названием (Red / Червоний).
- `element_id` сам определяет деталь и цвет.
- Существующий лот (та же деталь + цвет + состояние) обновляется, новый создаётся.

Наборы: `set_number;condition;quantity;price;old_price;completeness;age;...`. Минифигурки: `fig_number;condition;quantity;price`. Остатки и цены: `sku;quantity;price`.

## Интеграции

Каждая интеграция включается, когда в `.env` есть ключ. Без ключа магазин честно работает в ручном режиме и ничего не имитирует.

| Интеграция | Переменные | Без ключа |
| --- | --- | --- |
| Нова пошта: поиск городов и отделений/почтоматов при оформлении, статус ТТН | `NOVA_POSHTA_API_KEY` (кабинет НП → Налаштування → API) | Город и отделение вводятся вручную, ссылка на отслеживание работает |
| LiqPay: оплата картой, Apple Pay, Google Pay | `LIQPAY_PUBLIC_KEY`, `LIQPAY_PRIVATE_KEY`, `LIQPAY_SANDBOX` | Вариант «Оплата карткою» неактивен, доступен наложенный платёж |
| Укрпошта: статус отправления | `UKRPOSHTA_BEARER_TOKEN` | Ссылка на отслеживание |
| Почта (SMTP) | `EMAIL_HOST`, `EMAIL_HOST_USER`, `EMAIL_HOST_PASSWORD` | Письма выводятся в консоль сервера |

Ключ Новой почты не попадает в браузер: запросы идут через сервер (`/api/np/...`) с кешированием и ограничением частоты. Заказ становится «Оплачено» только после callback от LiqPay, у которого проверены подпись, сумма и валюта. Адрес callback: `https://ваш-домен/zamovlennia/liqpay/callback/`.

Код интеграций: `orders/shipping/novaposhta.py`, `orders/shipping/ukrposhta.py`, `orders/payments/liqpay.py`. Другой платёжный сервис (Monobank, WayForPay) добавляется ещё одним классом рядом с LiqPay.

## Развёртывание

**Docker:**

```bash
docker compose up --build
```

Поднимутся PostgreSQL и сайт на :8000. Каталог и демо-данные загружаются один раз:

```bash
docker compose exec web python manage.py setup_store
```

```bash
docker compose exec web python manage.py createsuperuser
```

**Render, Railway и похожие PaaS:** есть `Procfile` (`migrate` при релизе, сайт через gunicorn). Задайте переменные из `.env.example`, обязательно `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=0`, `DJANGO_ALLOWED_HOSTS`, `DJANGO_CSRF_TRUSTED_ORIGINS`, `DATABASE_URL`. Статика отдаётся через WhiteNoise. Для загружаемых фото подключите постоянный диск (`DJANGO_MEDIA_ROOT`) или S3-хранилище: на многих PaaS файловая система временная.

**VPS:** gunicorn за nginx (nginx отдаёт `/media/`), HTTPS через Let's Encrypt. После проверки HTTPS включите `DJANGO_HSTS_SECONDS=31536000`.

Проверка настроек для прода:

```bash
DJANGO_DEBUG=0 python manage.py check --deploy
```

## Безопасность

- Пароли хранятся хешированными (PBKDF2), действуют валидаторы сложности, после 8 неудачных входов вход блокируется на 15 минут.
- CSRF-защита всех форм, POST для всех изменений, Content-Security-Policy без inline-скриптов, `X-Frame-Options: DENY`, безопасные cookie и редирект на HTTPS в проде. HSTS включается переменной `DJANGO_HSTS_SECONDS`.
- Чужие заказы недоступны: страница заказа открывается владельцу, сотруднику или по секретной ссылке из письма.
- Загружаемые фото проверяются Pillow и перекодируются, у импортируемых файлов ограничены размер и количество строк.
- Секреты только в переменных окружения (`.env` в `.gitignore`).

## Структура

```
brickhub/
  config/      настройки, urls, wsgi
  core/        главная, статические страницы, SEO (JSON-LD, sitemap, robots), middleware безопасности
  catalog/     модели каталога и товаров, поиск, фильтры, генератор SVG деталей, импорт каталога, демо-данные
  cart/        корзина, промокоды, заказ списком
  orders/      оформление, статусы, письма, Новая почта / Укрпошта, LiqPay
  accounts/    пользователь (вход по e-mail), кабинет
  panel/       админ-панель, статистика, импорт/экспорт CSV и Excel
  templates/   HTML-шаблоны (украинский интерфейс)
  static/      CSS, JS, шрифты Inter и Unbounded, иконки
  data/        справочный каталог (catalog_full.json.gz) и выборка для демо (catalog_seed.json)
  tools/       скрипт сборки data/ из базы Rebrickable
  tests/       автотесты
```

Модели: `Product` (товар-лот) · `LegoSet` (набор) · `Part` (деталь) · `Element` (деталь + цвет = Element ID) · `Minifigure` · `Color` · `Category` · `Theme` (серия) · `User` · `Order` · `OrderItem` · `OrderStatusEvent` · `Payment` · `Review` · `Favorite` · `Inventory` · `InventoryMovement` · `StockNotification` · `Cart` · `CartItem` · `PromoCode`.
