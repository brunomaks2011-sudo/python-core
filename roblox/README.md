# Лесная карта для военной песочницы (Roblox)

`ForestMapGenerator.lua` — скрипт для Roblox Studio, который сам строит большую лесную карту
в стиле low-poly военного симулятора.

## Что получится

- Рельеф 2048×2048 studs (Smooth Terrain): холмы, гряды по краям карты, открытые луга.
- Плотные массивы ели и сосны (~4500 деревьев), сухие деревья, кусты, камни, валуны,
  поваленные деревья, пни.
- 2 асфальтовые трассы, грунтовые дороги, узкие тропы.
- 3 озера и 2 реки; там, где дороги пересекают реки, стоят мосты.
- Заброшенные военные лагеря (палатки, вышки, ДОТ, грузовики, ящики, бочки, мешки
  с песком, колючая проволока), разрушенная деревня, руины, лесопилка, охотничьи
  избушки, блокпост на трассе, пирсы, охотничьи вышки.
- Освещение: дымка (Atmosphere), тени, приглушённые цвета.

Превью (рендер тех же данных вне Roblox; в Studio материалы и дымка будут выглядеть
по-роблоксовски) лежит в папке [`preview/`](preview/).

## Как запустить

Открой в Roblox Studio **новое пустое место** (шаблон Baseplate).

**Через MCP-сервер `Roblox_Studio` (Claude Code на ПК):**

> Выполни в Studio через run_code весь код из файла `roblox/ForestMapGenerator.lua`.

**Вручную:** View → Command Bar → вставить весь файл → Enter.

Генерация займёт от ~30 секунд до пары минут, Studio может подвиснуть. В Output
появятся сообщения `[ForestMap] ...`, а в конце строка `Готово!`.

> Скрипт очищает весь Terrain, удаляет Baseplate и старую модель `ForestMap`.

## Настройки (в начале файла, таблица `CONFIG`)

| Параметр | Что делает |
|---|---|
| `SEED` | Другое число даёт другую карту |
| `MAP_SIZE` | Размер карты в studs (кратно 128) |
| `TREE_COUNT` | Количество деревьев. На слабом ПК поставь 2000–2500 |
| `BUSH_COUNT`, `ROCK_CLUSTERS`, `BOULDERS`, `FALLEN_TREES`, `STUMPS` | Плотность мелкой растительности и камней |
| `SET_LIGHTING` | Настраивать ли освещение и дымку |

## Структура в Workspace

```
ForestMap
├── Trees            деревья
├── Vegetation       кусты, поваленные деревья, пни
├── Rocks            камни и валуны
├── Locations        лагеря, деревня, руины, лесопилка, избушки, блокпост
├── Infrastructure   мосты, пирсы, охотничьи вышки
├── Boundary         невидимые стены по краю карты
└── Spawn            точка появления (в первом военном лагере)
```
