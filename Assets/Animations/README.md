# Assets/Animations

Mapped to `ReplicatedStorage.Assets.Animations` by `default.project.json`.

Soldiers (players and AI) are R15 rigs that use Roblox's public default R15
animations (idle, walk, run, jump, fall, climb, swim). Weapon-holding arms,
crouch and prone poses are procedural (`Client/Effects/StanceAnimator.luau`),
so no animation uploads are needed.

Put `Animation` instances here (as `.model.json`) to override them.
